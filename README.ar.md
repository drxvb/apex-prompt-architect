# APEX Prompt Architect — مُهَندِس البرومبت

> 🇬🇧 [English README](README.md) — هذا الملف هو النسخة العربية بالفصحى، وليس ترجمةً حرفية.

أداةٌ تُحوِّل البرومبت الخام (الفكرة الأولية أو التعليمات المبهمة) إلى **برومبت بجودة إنتاجية**، مُهيَّأ خصِّيصاً لإحدى المنصات الثلاث: **Claude** و**Kimi** و**MiniMax**.

الأداة مبنية وفق مواصفة [Agent Skills](https://agentskills.io)، وتعتمد منهجية **APEX 4D** الرباعية (التفكيك → التشخيص → التطوير → التسليم)، مع قائمة فحص جودة مكوَّنة من ١٢ نقطة، وتُخرِج نسختَين من البرومبت المُحسَّن: نسخة مُفصَّلة ونسخة مُختصَرة.

المواصفة الكاملة وبروتوكول التحويل وقواعد التكيُّف مع كل منصَّة موجودةٌ في **[`SKILL.md`](SKILL.md)**. هذا الـREADME نظرةٌ عامَّة في صفحة واحدة.

## ما الذي تفعله الأداة

تتلقَّى أيّاً مما يلي:
- فكرةً خاماً من سطر واحد ("أريد برومبت يقوم بـ...")
- مسودَّة أوَّلية ناقصة لبرومبت ما
- برومبت يعمل في نموذج لكنَّه يفشل في آخر
- مواصفة شخصيَّة لوكيل (الدور، الأهداف، المهام)

…ثم تُنتج برومبتاً مصقولاً ومُتكيِّفاً مع المنصَّة المستهدفة — النيَّة نفسها، لكن بثلاثة أشكال مختلفة بحسب المنصَّة المستهدَفة:

- **Claude**: سياق طويل، بنية XML، تلميحات تفكُّر صريحة
- **Kimi**: مرتبط بالوثائق، تفكيك خطوة بخطوة، مع فحص ذاتيّ
- **MiniMax**: مختصر، مباشر، الدور والمهمَّة في الجملة الأولى

## المنصَّات المدعومة

| المنصَّة | الحالة | ما الذي نُحسِّن من أجله |
|---|---|---|
| **Claude** | ✅ الهدف الأساسي | سياق طويل · استدلال انعكاسي · بنية XML · حساسية أمنية |
| **Kimi** | ✅ مدعومة | تحليل الوثائق الطويلة · تفكيك المهمَّة بوضوح · هرميَّة Markdown |
| **MiniMax** | ✅ مدعومة | تنفيذ سريع · برومبت مُحكَم · الدور والمهمَّة في الجملة الأولى |

## البداية السريعة

```bash
# المنصَّة الافتراضية هي Claude
python scripts/apex_workflow.py --input rough.md --output optimized.md

# استهداف Kimi بدلاً منها
python scripts/apex_workflow.py --input rough.md --platform kimi --output optimized.md

# المقارنة بين المنصَّات الثلاث
python scripts/apex_workflow.py --input rough.md --platform all --output-dir ./out/
```
