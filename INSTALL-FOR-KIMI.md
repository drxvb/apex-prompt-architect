# Installing APEX Prompt Architect for Kimi CLI

Kimi CLI does not import `.skill` ZIP bundles. This document is a **self-contained markdown installer** — hand the entire file to Kimi and ask it to recreate the skill tree on your local machine.

## Quick install (for Kimi CLI users)

Paste this prompt into Kimi:

```
Please read the file blocks below and recreate them on my local filesystem under
~/.kimi/skills/apex-prompt-architect/. Preserve directory structure exactly.
After creating all files, run `python ~/.kimi/skills/apex-prompt-architect/evals/test_known_fragility.py`
and report the result.
```

Then follow with the file blocks below.

## Configuration

After install, configure your LLM endpoint:

```bash
export LLM_API_URL=https://api.moonshot.ai/v1/chat/completions
export LLM_API_KEY=sk-...
export LLM_MODEL=kimi-k2-0905-preview
```

Or copy `config.example.json` to `config.json` and edit.

## Verifying the install

```bash
python ~/.kimi/skills/apex-prompt-architect/evals/test_known_fragility.py
# Expected: 10+/10+ passed

python ~/.kimi/skills/apex-prompt-architect/scripts/validate_prompt.py \
  --input ~/.kimi/skills/apex-prompt-architect/examples/01-vague-summarize/OUTPUT-kimi.md
# Expected: most checks pass (some warns expected on examples)
```

## How to use

Tell Kimi to load the skill's main prompt:

```
Load the system prompt from ~/.kimi/skills/apex-prompt-architect/prompts/apex-prompt-architect/for-kimi.md
and apply it to my following request.
```

Then describe your rough prompt — Kimi will apply the APEX 4D method and produce a Kimi-optimized output.
